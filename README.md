## 🚀 Featured Projects

### 🧠 [Recall — Real-Time Camera Memory Assistant](https://github.com/huzaif789/recall-spatial-ai)
Real-time AI camera-memory assistant built with **FastAPI, WebSockets, ChromaDB and Gemini Vision**. Features spoken answers, scene-change gating and retrieval evaluation.

### 🛡️ [AEGIS — AI-Powered Fraud Detection System](https://github.com/huzaif789/aegis-ai-fraud-detection)
End-to-end machine-learning fraud detection prototype combining **scikit-learn, FastAPI, real-time transaction simulation, explainable risk signals and an analytics dashboard**.

### ☁️ Production-Ready AWS VPC Infrastructure
Infrastructure-as-code project using **Terraform and AWS**, covering VPC networking, public/private subnets, Internet Gateway, NAT Gateway, route tables and security groups.

### 🔄 Linux E-Commerce ETL Pipeline
Automated analytics pipeline using **Python, Pandas, SQLAlchemy, PostgreSQL, Bash and Cron** to extract, transform, load and analyze e-commerce data.

### 📚 Production RAG with Reranking
Advanced PDF question-answering system using **Qdrant, PostgreSQL, Docker, document ingestion, retrieval, reranking and cited responses**.
